# marcelofelix

This is the source code for [marcelofelix.com](marcelofelix.com)!

## About

This is my personal website, which includes a **blog** and a **cv** resume page.
I like to work on plain text, so the articles are in `markdown` and the cv is redered from a `toml` file.

The website is hosted in cloudflare, uses Astro, and the **Papyrus** theme.

You can know more about it in this post:
- https://marcelofelix.com/posts/new-web

## Cloning

If you want to use this astro theme, you don't need to clone this repo or [marcelofpfelix/papyrus](https://github.com/marcelofpfelix/papyrus), it's easier to use [marcelofpfelix/papyrus-template](https://github.com/marcelofpfelix/papyrus-template) and follow this doc:
- https://papyrus.marcelofelix.com/collections/docs/install-configure-papyrus
